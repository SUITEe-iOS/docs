The Properties & Units section lets you manage your entire property portfolio and the individual rooms, apartments, or spaces within each property.

## Key concepts

Before diving in, let's clarify two important terms:

| Term | What It Means | Example |
| :--- | :--- | :--- |
| **Property** | The building or location you manage | "Hotel Sunrise Vienna", "Lakeside Apartments Munich" |
| **Unit** | An individual room, apartment, or space within a property | "Room 101", "Suite 305", "Apartment A2" |

A single property can contain many units. If you manage multiple buildings, each building is a separate property.

---

## Viewing your properties

When you navigate to the Properties section, you'll see a **list of all properties** you manage. For each property, you can typically see:

- Property name and address
- Number of units
- Current occupancy status
- Device health summary

## Adding a new property

<Steps>
  <Step title="Navigate to Properties">
    From the dashboard sidebar, click on **Properties** or **Properties & Units**.
  </Step>

  <Step title="Click 'Add New Property'">
    Click the **"Add New Property"** button (usually in the top-right corner).
    
    <Frame>
      <img src="/images/dashboard-property-switcher.png" alt="Property switcher dropdown" />
    </Frame>
  </Step>

  <Step title="Enter property details">
    Fill in the required information:

    | Field | Description |
    | :--- | :--- |
    | **Property Name** | The name of your building or location |
    | **Address** | Full street address including city and postal code |
    | **Number of Units** | How many rooms/apartments the property has |
    | **Contact Information** | Phone number and email for the property |
  </Step>

  <Step title="Save the property">
    Click **"Save"** to create the property. It will now appear in your properties list.
  </Step>
</Steps>

## Adding units to a property

Once you've created a property, you need to add the individual units (rooms/apartments) within it.

<Steps>
  <Step title="Select the property">
    Click on the property you want to add units to.
  </Step>

  <Step title="Navigate to Units">
    Within the property view, find the **Units** section or tab.
  </Step>

  <Step title="Click 'Add Unit'">
    Click the **"Add Unit"** button.
  </Step>

  <Step title="Enter unit details">
    For each unit, provide:
    - **Unit name/number** (e.g., "Room 101", "Apartment A2")
    - **Unit type** (e.g., single room, double room, suite, apartment)
    - **Floor** (optional)
  </Step>

  <Step title="Assign devices (optional)">
    If smart devices have already been installed, assign them to this unit:
    - Link the **smart lock** for the unit's door
    - Link the **thermostat** for climate control
    - Link any **sensors** (occupancy, window, etc.)

    <Info>
      You can assign devices later — they don't need to be linked when you first create the unit. See [Smart Devices](/devices/smart-locks) for more on device setup.
    </Info>
  </Step>

  <Step title="Save the unit">
    Click **"Save"**. The unit now appears within the property and can receive reservations and device assignments.
  </Step>
</Steps>

## Editing property or unit details

You can update property and unit information at any time:

1. Navigate to the property or unit you want to edit
2. Click the **"Edit"** button or the pencil/gear icon
3. Make your changes
4. Click **"Save"**

<Warning>
  Be careful when changing unit names or numbers if there are active reservations. Changing a unit's identifier may affect how reservations are mapped from your PMS.
</Warning>

## Monitoring unit status

Each unit in the dashboard shows its current status:

| Status | What It Means |
| :--- | :--- |
| **Occupied** | A guest is currently checked in to this unit |
| **Vacant** | No guest; the unit is available for the next reservation |
| **Cleaning** | The guest has checked out and housekeeping has been notified |
| **Maintenance** | The unit is under maintenance and not available for booking |

<Tip>
  Use the unit status view to quickly identify which rooms need housekeeping attention and which are ready for the next guest. This is especially useful during high-turnover periods.
</Tip>
