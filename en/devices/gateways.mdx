Gateways are small hub devices that act as the **communication bridge** between all your smart devices (locks, thermostats, sensors) and the SUITEe cloud dashboard. Without a gateway, devices cannot send data to the dashboard or receive instructions from the system.

## What is a gateway?

Think of a gateway as a **translator and relay station**:
- Smart devices (locks, thermostats, sensors) communicate using short-range wireless protocols
- The gateway **receives** these communications
- It then **relays** them over your property's Wi-Fi/internet to the SUITEe cloud
- Dashboard commands are sent back down through the gateway to the devices

<Info>
  Each property needs **at least one gateway**. Larger properties may need multiple gateways to ensure coverage across all floors and areas.
</Info>

---

## How gateways work

<Steps>
  <Step title="Gateway connects to your network">
    The gateway is plugged into power and connects to your property's **Wi-Fi or ethernet network**.
  </Step>

  <Step title="Smart devices connect to the gateway">
    All nearby smart devices (locks, thermostats, sensors) establish a connection with the gateway using short-range wireless protocols.
  </Step>

  <Step title="Data flows both ways">
    - **Devices → Gateway → Cloud:** Sensor readings, lock status, temperature data are sent to the dashboard
    - **Cloud → Gateway → Devices:** Remote commands (unlock door, adjust temperature) are sent to devices
  </Step>

  <Step title="Dashboard shows real-time status">
    Staff see live device status, can send remote commands, and receive alerts — all through the gateway connection.
  </Step>
</Steps>

## Gateway setup requirements

| Requirement | Details |
| :--- | :--- |
| **Power** | Constant power supply (plugged into a wall outlet) |
| **Network** | Wi-Fi or ethernet connection to the internet |
| **Location** | Central location with good coverage to all devices |
| **Quantity** | At least one per property; more for large or multi-floor properties |

<Warning>
  **Setup order matters:** Always set up gateways **before** adding other devices. The gateway needs to be online and connected so that locks, thermostats, and sensors can communicate through it.
</Warning>

---

## Why gateways matter

Without a functioning gateway:

| Impact | Description |
| :--- | :--- |
| **No remote monitoring** | Dashboard cannot see device status or receive sensor data |
| **No remote commands** | Staff cannot remotely unlock doors or adjust temperatures |
| **No real-time alerts** | Battery warnings, offline device alerts, etc. won't appear |
| **Devices still work locally** | Locks and PINs still function — just without cloud connectivity |

<Info>
  **Important:** Even if a gateway goes offline, smart locks still work with PIN codes. Guests can still enter their rooms. However, you lose dashboard visibility and remote control until the gateway is back online.
</Info>

## Monitoring gateway status

From the dashboard, you can see the status of each gateway:

| Status | Meaning |
| :--- | :--- |
| **Online** | Gateway is connected and operating normally |
| **Offline** | Gateway has lost connection — check power and network |
| **Degraded** | Gateway is connected but experiencing performance issues |

### Troubleshooting an offline gateway

<Steps>
  <Step title="Check power">
    Ensure the gateway is **plugged in** and the power outlet is working.
  </Step>
  <Step title="Check network">
    Verify that the **Wi-Fi network** or ethernet cable is connected and the internet is working.
  </Step>
  <Step title="Restart the gateway">
    **Power cycle** the gateway — unplug it, wait 30 seconds, and plug it back in.
  </Step>
  <Step title="Check placement">
    If devices are far from the gateway, consider repositioning it for better coverage or adding an additional gateway.
  </Step>
  <Step title="Contact support">
    If the problem persists after these steps, contact [SUITEe support](https://suite-e.com/contact-us/).
  </Step>
</Steps>

<Tip>
  **Setup tip:** Power on gateways approximately **30 minutes** before starting the device setup process. This gives them time to establish a stable connection with the SUITEe cloud.
</Tip>
