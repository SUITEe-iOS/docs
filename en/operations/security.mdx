Security is a top priority for SUITEe. The platform is designed to keep your property, guests, and data safe — with multiple layers of protection and built-in fallbacks for every scenario.

## Access security

| Security Feature | How It Works |
| :--- | :--- |
| **Unique codes for each guest** | Every guest gets their own unique PIN or mobile key — no shared access |
| **Time-limited access** | Credentials only work during the guest's stay and expire automatically at check-out |
| **Audit trail** | Every door opening is logged with the time, date, and who opened it |
| **Remote revocation** | Staff can **immediately revoke** anyone's access from the dashboard |
| **Multi-level control** | Access can be granted for specific areas only (room, building, amenities) |

<Info>
  The combination of unique credentials, time-limited access, and a complete audit trail provides significantly **better security than physical keys**, which can be copied, lost, or passed to unauthorised people.
</Info>

## What happens during emergencies?

SUITEe is designed to remain operational even when things go wrong. Here's what happens in common emergency scenarios:

### Wi-Fi or internet outage

<AccordionGroup>
  <Accordion title="What still works">
    - Guests can still **unlock doors using their PIN code** — PINs work offline
    - Smart locks operate on **battery power** — they don't need internet to function
    - All essential devices can be **operated manually** as a fallback
  </Accordion>

  <Accordion title="What doesn't work during an outage">
    - **Dashboard** loses real-time device status (no data flowing from devices)
    - **Remote commands** (like remotely unlocking a door) won't work
    - **New access credentials** cannot be generated until connectivity is restored
  </Accordion>

  <Accordion title="What happens when internet is restored">
    - All devices **automatically reconnect** and sync with the dashboard
    - Any data collected during the outage is **uploaded retroactively**
    - No data is lost — the system resumes normal operation seamlessly
  </Accordion>
</AccordionGroup>

### Power outage

| Aspect | What Happens |
| :--- | :--- |
| **Smart locks** | Continue working on **battery power** — guests can still use PIN codes |
| **Gateways** | Go offline (need power) — dashboard connectivity lost until power returns |
| **Thermostats** | Pause until power returns — then resume normal operation |
| **Sensors** | Continue on battery power |
| **After power returns** | Everything **resynchronises automatically** — no manual intervention needed |

<Warning>
  **No data is lost** during a power outage. All access logs, sensor data, and device states are preserved and synced when power returns.
</Warning>

### System failure

Even in the unlikely event of a complete system failure:

- **All smart devices have manual fallback options** — doors can be opened with manual keys
- **Staff always maintain full control** through built-in backup features
- **No guest is ever locked out** — the manual key override ensures access at all times

## Data protection (GDPR)

SUITEe is fully GDPR-compliant, meaning guest data is handled according to strict European data protection regulations:

| GDPR Principle | How SUITEe Complies |
| :--- | :--- |
| **Data minimisation** | Only essential guest data is processed (name, room, dates) |
| **Purpose limitation** | Guest data is used only for access and stay management |
| **Security** | Data is encrypted in transit and at rest |
| **Access control** | Only authorised staff can access guest data (role-based permissions) |
| **Data retention** | Guest data is retained only as long as necessary |
| **Right to erasure** | Guest data can be deleted upon request |

## Security best practices

<AccordionGroup>
  <Accordion title="For property managers">
    - **Review user access regularly** — Remove accounts for former employees promptly
    - **Use role-based permissions** — Don't give everyone Super Admin access
    - **Monitor the audit trail** — Review access logs periodically for unusual activity
    - **Keep devices updated** — Ensure all devices are running the latest firmware
    - **Maintain manual keys** — Keep manual override keys in a secure, accessible location
  </Accordion>

  <Accordion title="For front desk staff">
    - **Never share your login credentials** — Each person should have their own account
    - **Use strong passwords** — Follow password requirements and change them periodically
    - **Log out on shared computers** — Always log out when leaving a shared workstation
    - **Verify identity before generating new access** — If someone claims to be a guest, verify their reservation before creating a new PIN
  </Accordion>

  <Accordion title="For guests (guidance to share)">
    - **Don't share your PIN code** with others
    - **Close the Guest Web App** when not in use
    - **Report suspicious activity** — If someone is trying to access your room, contact the property
  </Accordion>
</AccordionGroup>

<Tip>
  Security is a shared responsibility. SUITEe provides the tools and technology, but proper security practices by staff and guests ensure the system works at its best.
</Tip>
