---

Wenn Sie Ihr SUITEe-Passwort vergessen haben, können Sie es über den Passwort-Wiederherstellungsablauf schnell zurücksetzen. Das System sendet einen Link zum Zurücksetzen an Ihre registrierte E-Mail-Adresse.

## So setzen Sie Ihr Passwort zurück

<Steps>
  <Step title="Gehen Sie zur Anmeldeseite">
    Rufen Sie **[https://hotel.suite-e.com/auth](https://hotel.suite-e.com/auth)** in Ihrem Browser auf (oder gehen Sie direkt zu **[https://hotel.suite-e.com/auth/forgot-password](https://hotel.suite-e.com/auth/forgot-password)**). Sie sehen die gewohnte Anmeldeseite.
  </Step>

  <Step title="Klicken Sie auf 'Passwort vergessen?'">
    Unter dem Passwortfeld auf der Anmeldeseite klicken Sie auf den Link **"Passwort vergessen?"** (oder gehen Sie direkt zu [https://hotel.suite-e.com/auth/forgot-password](https://hotel.suite-e.com/auth/forgot-password)). Sie sehen den Bildschirm **Passwort zurücksetzen**:

    <Frame>
      <img src="/images/forgot-password-german.png" alt="SUITEe deutscher Passwort zurücksetzen Bildschirm" />
    </Frame>
  </Step>

  <Step title="Geben Sie Ihre E-Mail-Adresse ein">
    Geben Sie auf dem Bildschirm zum Zurücksetzen des Passworts die mit Ihrem SUITEe-Konto verknüpfte **E-Mail-Adresse** in das Feld **E-Mail** ein. Wenn das Feld leer abgeschickt wird, zeigt die Plattform sofort einen Validierungshinweis an:

    <Frame>
      <img src="/images/forgot-password-german-validation.png" alt="Validierungsfehler, wenn das erforderliche E-Mail-Feld leer ist" />
    </Frame>

    <Info>
      Stellen Sie sicher, dass Sie dieselbe E-Mail-Adresse eingeben, die beim Erstellen Ihres SUITEe-Kontos verwendet wurde. Wenn Sie unsicher sind, welche E-Mail verknüpft ist, wenden Sie sich an Ihren Unterkunfts-Administrator.
    </Info>
  </Step>

  <Step title="Klicken Sie auf 'E-Mail verifizieren'">
    Klicken Sie auf die Schaltfläche **"E-Mail verifizieren"**. Das System zeigt ein Bestätigungsbanner an, das bestätigt, dass der Link zum Zurücksetzen an Ihren Posteingang gesendet wurde:

    <Frame>
      <img src="/images/forgot-password-german-submitted.png" alt="Bestätigungsmeldung nach dem Anfordern des Links zum Zurücksetzen des Passworts" />
    </Frame>
  </Step>

  <Step title="Prüfen Sie Ihren E-Mail-Posteingang">
    Öffnen Sie Ihren E-Mail-Posteingang und suchen Sie nach einer Nachricht von SUITEe mit einer Betreffzeile, die "Passwort zurücksetzen" oder Ähnliches enthält.

    <Warning>
      Wenn Sie die E-Mail nicht innerhalb weniger Minuten sehen:

      - Prüfen Sie Ihren **Spam-** oder **Junk-E-Mail-Ordner**
      - Stellen Sie sicher, dass Sie die korrekte E-Mail-Adresse eingegeben haben
      - Versuchen Sie, den Link zum Zurücksetzen erneut zu senden
    </Warning>
  </Step>

  <Step title="Klicken Sie auf den Link zum Zurücksetzen">
    Öffnen Sie die E-Mail und klicken Sie auf den **Link zum Zurücksetzen des Passworts**. Dadurch gelangen Sie auf eine Seite, auf der Sie ein neues Passwort festlegen können.

    <Warning>
      Links zum Zurücksetzen **laufen in der Regel nach einer begrenzten Zeit ab** (meist 30 Minuten bis 1 Stunde). Wenn der Link abgelaufen ist, gehen Sie zurück zu Schritt 2 und fordern Sie einen neuen an.
    </Warning>
  </Step>

  <Step title="Legen Sie Ihr neues Passwort fest">
    1. Geben Sie Ihr **neues Passwort** in das Feld "Neues Passwort" ein
    2. **Bestätigen** Sie das neue Passwort, indem Sie es erneut eingeben
    3. Klicken Sie auf **"Passwort zurücksetzen"** oder **"Speichern"**

    <Tip>
      Wählen Sie ein starkes Passwort, das Folgendes enthält:

      - Mindestens 8 Zeichen
      - Eine Mischung aus Groß- und Kleinbuchstaben
      - Mindestens eine Zahl
      - Mindestens ein Sonderzeichen (z. B. `!`, `@`, `#`)
    </Tip>
  </Step>

  <Step title="Melden Sie sich mit Ihrem neuen Passwort an">
    Nach erfolgreichem Zurücksetzen werden Sie zur Anmeldeseite weitergeleitet. Geben Sie Ihre E-Mail-Adresse und Ihr **neues Passwort** ein, um sich anzumelden.
  </Step>
</Steps>

## Häufig gestellte Fragen

<AccordionGroup>
  <Accordion title="Wie lange dauert es, bis die E-Mail zum Zurücksetzen ankommt?">
    Die E-Mail zum Zurücksetzen trifft in der Regel innerhalb von **1–2 Minuten** ein. Wenn es länger dauert, prüfen Sie Ihren Spam-Ordner oder versuchen Sie, einen neuen Link zum Zurücksetzen anzufordern.
  </Accordion>

  <Accordion title="Kann ich mein Passwort über mein Smartphone zurücksetzen?">
    Ja. Der Ablauf zum Zurücksetzen des Passworts funktioniert auf jedem Gerät mit einem Webbrowser — Desktop, Tablet oder Smartphone.
  </Accordion>

  <Accordion title="Was ist, wenn ich nach dem Zurücksetzen immer noch nicht auf mein Konto zugreifen kann?">
    Wenden Sie sich an Ihren Unterkunfts-Administrator oder das [SUITEe-Support-Team](https://suite-e.com/contact-us/). Diese können Ihren Kontostatus überprüfen und Ihnen helfen, den Zugriff wiederzuerlangen.
  </Accordion>
</AccordionGroup>
