SUITEe bietet messbare Verbesserungen in drei Kernbereichen: **Kostenersparnis**, **operative Effizienz** und **Gäste-Erlebnis**. Hier ist eine klare Übersicht darüber, was sich ändert, wenn Sie SUITEe einsetzen.

## Mit SUITEe vs. Ohne SUITEe

| Bereich | Ohne SUITEe | Mit SUITEe |
| :--- | :--- | :--- |
| **Rezeption** | 24/7-Rezeption erforderlich — teure Nachtschichten | 24/7 Self-Check-in — Gäste kommen jederzeit ohne Personal an |
| **Schlüssel & Zugang** | Physische Schlüssel gehen verloren → laufende Wiederbeschaffungskosten | Sichere mobile Schlüssel und PIN-Codes — automatisch erstellt und verwaltet |
| **Energie** | Heizung/Kühlung läuft in leeren Zimmern — verschwendete Energie | Smarte Sensoren erkennen Abwesenheit → Energieeinsparung greift sofort |
| **Gästeregistrierung** | Manueller Check-in an der Rezeption — Warteschlangen und Wartezeiten | Online-Registrierung vor der Anreise — genau wie beim Flugzeug-Check-in |
| **Modernisierung** | Teure Renovierungen, um "smart" zu werden | Hardware-Nachrüstung in wenigen Minuten — ohne Baustelle, ohne neue Verkabelung |
| **Automatisierung** | Manuelle Arbeitsabläufe beim Personal — ineffizient und fehleranfällig | PMS-gesteuerte Automatisierungen — jeder Schritt wird im Hintergrund end-to-end abgewickelt |
| **Ausfallsicherheit** | Einzelner Schwachpunkt, wenn Systeme ausfallen | Integrierte manuelle Ausfalloptionen — jederzeit volle Kontrolle |
| **Infrastruktur** | Viele unzusammenhängende Systeme | Ein einheitliches Ökosystem — Software und Hardware perfekt aufeinander abgestimmt |

## Vorteile nach Rolle

### Für Eigentümer und Manager von Unterkünften

- **Personalkosten drastisch senken** — Keine 24/7-Rezeptionsbesetzung mehr nötig, insbesondere keine teuren Nachtschichten
- **Energierechnungen reduzieren** — Smarte Sensoren und automatisierte Klimasteuerung verhindern Energieverschwendung in unbelegten Zimmern
- **Mühelos skalieren** — Verwaltung mehrerer Objekte über ein einziges Dashboard, ohne physisch vor Ort sein zu müssen
- **Modernisieren ohne Renovierung** — Die Nachrüstgeräte von SUITEe werden in etwa einer Stunde pro Zimmer über bestehender Hardware installiert

### Für Betriebs- und Rezeptionspersonal

- **Weniger manuelle Arbeit** — Zugangscodes, Check-in-Anweisungen und Zimmervorbereitung erfolgen vollautomatisch
- **Echtzeit-Übersicht** — Das Dashboard zeigt Zimmerstatus, Gerätestatus und Warnmeldungen auf einen Blick
- **Proaktive Warnmeldungen** — Werden Sie über niedrige Akkustände, Offline-Geräte oder ungewöhnliche Zugriffe informiert, bevor daraus Probleme werden
- **Einfacher Gästesupport** — Falls ein Gast ein Problem hat, erstellen Sie in Sekundenschnelle über das Dashboard einen neuen Zugangscode oder passen Einstellungen an

### Für Gäste

- **Jederzeit ankommen** — Keine Abstimmung mit Rezeptionszeiten nötig; Check-in um 2 Uhr nachts ist problemlos möglich
- **Kein App-Download** — Die Gäste-Web-App läuft direkt im Browser des Smartphones
- **Zimmerkomfort bei Ankunft** — Das Zimmer ist bereits vorgeheizt oder vorgekühlt, bevor Sie es betreten
- **Steuerung über das Smartphone** — Temperatur anpassen, Türen ver- und entriegeln und Zusatzangebote nutzen direkt aus der Gäste-Web-App
- **Mühelose Abreise** — Einfach abreisen; der Zugang erlischt automatisch zur Check-out-Zeit

## Energieeinsparungen im Detail

Die Energieautomatisierung von SUITEe funktioniert in fünf Szenarien:

| Szenario | Was passiert |
| :--- | :--- |
| **Zimmer gebucht, Gast noch nicht angekommen** | Zimmer bleibt im Eco-Modus; heizt/kühlt kurz vor dem Check-in vor |
| **Gast im Zimmer** | Zimmer läuft im Gäste-Modus (angenehme Wohlfühltemperatur) |
| **Gast verlässt das Zimmer vorübergehend** | Sensoren erkennen Abwesenheit → Heizung/Kühlung wird nach einer eingestellten Zeit reduziert |
| **Gast öffnet ein Fenster** | Fenstersensor erkennt dies → Heizung/Kühlung pausiert, um Verschwendung zu vermeiden |
| **Gast checkt aus** | Zimmer schaltet sofort in den Eco-Modus bis zum nächsten Gast |

<Tip>
  Die Energieeinsparungen summieren sich über Ihre gesamte Unterkunft. Je mehr Zimmer Sie haben, desto größer ist die Auswirkung auf Ihre Nebenkosten — besonders in Zeiten, in denen die Zimmer nicht voll belegt sind.
</Tip>
