Licht- und Schaltmodule sind smarte Alternativen zu herkömmlichen Lichtschaltern und Steckdosen. Sie ermöglichen die Fernsteuerung und Automatisierung der Raumbeleuchtung sowie anderer elektrischer Geräte.

## Was sind Licht- & Schaltmodule?

Die smarten Schaltmodule von SUITEe:

- **ersetzen herkömmliche Lichtschalter** in Gästezimmern und Gemeinschaftsbereichen
- ermöglichen die **Fernsteuerung** der Raumbeleuchtung über das Dashboard
- können **automatisiert** werden, z. B. Licht ausschalten, wenn ein Raum leer ist
- ermöglichen Gästen die **Steuerung der Beleuchtung** über die Gäste-Web-App auf ihrem Smartphone

---

## So funktionieren sie

| Funktion | Beschreibung |
| :--- | :--- |
| **Fernsteuerung** | Mitarbeiter können die Beleuchtung eines beliebigen Raums über das Dashboard ein- oder ausschalten |
| **Steuerung durch Gäste** | Gäste können die Beleuchtung über die Gäste-Web-App steuern |
| **Automatisierung** | Die Beleuchtung wird automatisch ausgeschaltet, wenn der Präsenzsensor erkennt, dass der Raum leer ist |
| **Manuelle Steuerung** | Der Schalter funktioniert weiterhin wie ein normaler Lichtschalter — Gäste können ihn auch manuell bedienen |
| **Zeitplanung** | Die Beleuchtung kann so eingestellt werden, dass sie zu bestimmten Zeiten ein- oder ausgeschaltet wird, z. B. Flurbeleuchtung in der Nacht |

---

## Automatisierungsszenarien

<AccordionGroup>
  <Accordion title="Gast checkt aus → Licht aus">
    Wenn ein Gast auscheckt, werden alle Lichter im Zimmer **automatisch ausgeschaltet**, um Energie zu sparen. Mitarbeiter müssen nicht jedes Zimmer einzeln aufsuchen, um die Beleuchtung auszuschalten.
  </Accordion>

  <Accordion title="Raum längere Zeit leer → Licht aus">
    Wenn der Präsenzsensor erkennt, dass der Raum für einen festgelegten Zeitraum leer ist, z. B. 30 Minuten, wird die Beleuchtung automatisch gedimmt oder ausgeschaltet.
  </Accordion>

  <Accordion title="Willkommensbeleuchtung vor der Anreise">
    Vor der Ankunft eines Gastes können bestimmte Lichter eingeschaltet werden, um eine **einladende Atmosphäre** zu schaffen — beispielsweise die Eingangsbeleuchtung, Nachttischlampe oder Badezimmerbeleuchtung.
  </Accordion>

  <Accordion title="Zeitplanung für Gemeinschaftsbereiche">
    Die Beleuchtung in Fluren, Lobbys und Außenbereichen kann so geplant werden, dass sie zu bestimmten Zeiten ein- oder ausgeschaltet wird, z. B. gedimmte Flurbeleuchtung nach Mitternacht.
  </Accordion>
</AccordionGroup>

## Installation

Licht- und Schaltmodule sind für eine **einfache Nachrüstung** konzipiert:

- Sie passen in **Standard-Unterputzdosen**, die auch für herkömmliche Schalter verwendet werden
- Ein qualifizierter Elektriker kann die vorhandenen Schalter schnell austauschen
- Es ist keine neue Verkabelung erforderlich — die vorhandenen elektrischen Anschlüsse werden verwendet
- Nach der Installation verbinden sich die Module über das Gateway mit dem System

<Info>
  Wie alle SUITEe-Geräte werden auch die Lichtmodule vor dem Versand **vorkonfiguriert**. Nach der physischen Installation erscheinen sie automatisch im Dashboard und können den entsprechenden Räumen zugeordnet werden.
</Info>

## Überwachung und Steuerung

Über das Dashboard können Mitarbeiter:

| Aktion | Beschreibung |
| :--- | :--- |
| **Lichtstatus anzeigen** | Sehen Sie, welche Lichter in den verschiedenen Räumen ein- oder ausgeschaltet sind |
| **Licht schalten** | Schalten Sie einzelne Lichter aus der Ferne ein oder aus |
| **Gerätestatus prüfen** | Überwachen Sie, ob das Schaltmodul online ist und ordnungsgemäß funktioniert |
| **Energieverbrauch anzeigen** | Verfolgen Sie den Energieverbrauch der Beleuchtung, sofern dies vom jeweiligen Modul unterstützt wird |
