Smarte Türschlösser sind ein zentraler Bestandteil der Zugangsautomatisierung von SUITEe. Sie ersetzen oder ergänzen herkömmliche Türschlösser und ermöglichen Gästen, Türen mit ihrem Smartphone oder einem PIN-Code zu öffnen — ganz ohne physischen Schlüssel.

## Was sind smarte Türschlösser?

Die smarten Schlösser von SUITEe sind **digitale Schlösser**, die auf verschiedene Arten geöffnet werden können:

- Mit einem **mobilen Schlüssel** über den Smartphone-Browser des Gastes
- Mit einem **PIN-Code**, der über das Tastenfeld des Schlosses eingegeben wird
- Mit einem **manuellen Schlüssel** als physische Notöffnung

<Info>
  Smarte Schlösser sind **batteriebetrieben** und funktionieren unabhängig von WLAN oder Internet. Auch bei einem Internetausfall können Gäste weiterhin ihren PIN-Code verwenden, um die Tür zu öffnen.
</Info>

---

## So funktionieren smarte Türschlösser

<Steps>
  <Step title="Reservierung wird aus dem PMS synchronisiert">
    Wenn eine Buchung in Ihrem PMS erstellt wird, erhält SUITEe die Reservierungsdetails und erstellt die entsprechenden Zugangsdaten.
  </Step>

  <Step title="Zugangsdaten werden erstellt">
    SUITEe erstellt einen **eindeutigen PIN-Code** und/oder einen **mobilen Schlüssel** für den Gast. Diese Zugangsdaten sind mit dem jeweiligen Schloss der dem Gast zugewiesenen Zimmertür verknüpft.
  </Step>

  <Step title="Zugangsdaten werden zur Check-in-Zeit aktiviert">
    Zur geplanten Check-in-Zeit werden die Zugangsdaten aktiv. Der Gast kann nun seine Tür öffnen.
  </Step>

  <Step title="Gast öffnet die Tür">
    Der Gast kann entweder:

    - die **Gäste-Web-App** auf seinem Smartphone öffnen und auf **„Öffnen“** tippen oder
    - seinen **PIN-Code** über das Tastenfeld des Schlosses eingeben.
  </Step>

  <Step title="Zugangsdaten laufen beim Check-out ab">
    Zur Check-out-Zeit funktionieren der PIN-Code und der mobile Schlüssel automatisch nicht mehr. Das Schloss bleibt für den nächsten Gast gesichert.
  </Step>
</Steps>

## Wo smarte Schlösser eingesetzt werden

| Einsatzort | Zweck |
| :--- | :--- |
| **Zimmertüren** | Primärer Zugang des Gastes zu seinem Zimmer |
| **Gebäudeeingänge** | Haupteingang zur Unterkunft |
| **Brandschutztüren** | Gesicherte Türen in Fluren und Treppenhäusern |
| **Türen zu Gemeinschaftsbereichen** | Zugang zu Spa, Fitnessraum, Pool oder Parkgarage |

## Batteriemanagement

Smarte Schlösser werden mit **Standardbatterien** betrieben und benötigen keine feste Stromverkabelung.

| Aspekt | Details |
| :--- | :--- |
| **Batterietyp** | Standardbatterien, typischerweise AA oder CR123A, abhängig vom Schlossmodell |
| **Batterielaufzeit** | Mehrere Monate bei normaler Nutzung |
| **Warnung bei niedrigem Batteriestand** | Das Dashboard informiert Sie, wenn der Batteriestand eines Schlosses niedrig wird |
| **Batteriewechsel** | Wechseln Sie die Batterien, bevor sie vollständig entladen sind. Das Dashboard warnt Sie rechtzeitig. |

<Warning>
  **Ignorieren Sie Warnungen bei niedrigem Batteriestand nicht.** Wenn die Batterie eines Schlosses vollständig entladen ist, können Gäste weder ihren PIN-Code noch den mobilen Schlüssel verwenden. Das Schloss kann weiterhin mit dem manuellen Schlüssel geöffnet werden, dadurch entfällt jedoch der Vorteil der automatisierten Zugangslösung. Wechseln Sie die Batterien daher möglichst schnell nach einer entsprechenden Warnung.
</Warning>

## Manuelle Notöffnung mit Schlüssel

Jedes smarte Türschloss von SUITEe verfügt über eine **manuelle Schlüsselöffnung** — ein herkömmliches Schlüsselloch, das als Backup verwendet werden kann.

- Mitarbeiter sollten die manuellen Schlüssel an einem sicheren Ort aufbewahren.
- Verwenden Sie die manuellen Schlüssel nur, wenn die digitalen Zugangsmethoden nicht funktionieren, beispielsweise bei einer vollständig entladenen Batterie oder einem Systemfehler.
- Manuelle Türöffnungen werden **nicht auf dieselbe Weise protokolliert** wie digitale Zugriffe und sollten daher nur bei Bedarf verwendet werden.

<Tip>
  **Empfehlung:** Bewahren Sie einen Satz manueller Ersatzschlüssel in einem abschließbaren Schlüsselschrank an der Rezeption oder im Büro des Managers auf. Kennzeichnen Sie die Schlüssel eindeutig mit der jeweiligen Zimmernummer.
</Tip>

## Schlossstatus überwachen

Über das Dashboard können Sie die smarten Schlösser Ihrer Unterkunft überwachen:

| Spalte | Beschreibung |
| :--- | :--- |
| **Zimmername** | Zimmer oder Einheit, dem das Schloss zugeordnet ist |
| **Gerät** | Name und Kategorie des Schlosses, z. B. *Haupttürschloss 85 German U* |
| **Batterie** | Aktueller Batteriestand in Prozent, z. B. 86 %. Bei einem zu niedrigen Batteriestand werden Warnungen angezeigt. |
| **Verbindung** | Netzwerkstatus des Schlosses — Online oder Offline. Zeigt an, ob das Schloss über das Gateway kommuniziert. |
| **Zustand** | Physischer Zustand des Schlosses — verriegelt oder entriegelt |

### Tür aus der Ferne öffnen

Mitarbeiter können eine Tür direkt über das Dashboard aus der Ferne entriegeln, beispielsweise wenn ein Gast ausgesperrt ist oder in einer dringenden Situation.

Wenn Sie ein Schloss auswählen, öffnet sich der Bereich **Geräteaktionen** mit einer deutlich sichtbaren Schaltfläche zum Entriegeln der Tür.
