Der Bereich **Immobilien & Einheiten** dient zur Verwaltung Ihrer Unterkünfte und der einzelnen Zimmer, Apartments oder Bereiche innerhalb einer Immobilie.

## Grundbegriffe

Bevor Sie beginnen, sind zwei Begriffe wichtig:

| Begriff | Bedeutung | Beispiel |
| :--- | :--- | :--- |
| **Immobilie** | Das Gebäude oder der Standort, den Sie verwalten | „Hotel Sunrise Vienna“, „Lakeside Apartments Munich“ |
| **Einheit** | Ein einzelnes Zimmer, Apartment oder ein anderer Bereich innerhalb einer Immobilie | „Zimmer 101“, „Suite 305“, „Apartment A2“ |

Eine Immobilie kann mehrere Einheiten enthalten. Wenn Sie mehrere Gebäude oder Standorte verwalten, können diese als separate Immobilien in SUITEe angelegt werden.

## Neue Immobilie einrichten

Die Einrichtung einer neuen Immobilie hängt von den Berechtigungen und der Konfiguration Ihrer SUITEe-Umgebung ab.

Nach der Einrichtung können die grundlegenden Daten der Immobilie unter [Einstellungen](/de/dashboard/settings) verwaltet werden.

Zu den typischen Immobilieninformationen gehören:

| Information | Beschreibung |
| :--- | :--- |
| **Name** | Name des Hotels, Apartments oder Standorts |
| **Adresse** | Vollständige Adresse der Immobilie |
| **Kontaktinformationen** | E-Mail-Adresse und Telefonnummern der Unterkunft |
| **Check-in / Check-out** | Standardzeiten für Anreise und Abreise |
| **PMS-Typ** | Das für die Immobilie konfigurierte Property Management System |
| **Zeitzone** | Lokale Zeitzone der Unterkunft |

## Zimmer und Einheiten verwalten

Nachdem eine Immobilie eingerichtet wurde, können die einzelnen Zimmer oder Einheiten im Bereich [Zimmer](/de/dashboard/rooms) verwaltet werden.

Dort können Sie beispielsweise:

- Zimmer und Einheiten anzeigen
- Neue Zimmer hinzufügen
- Bestehende Zimmer bearbeiten
- Zimmerinformationen verwalten
- Zugeordnete Geräte überprüfen

---

## Neue Einheit hinzufügen

Um ein neues Zimmer oder eine neue Einheit anzulegen, wechseln Sie zum Bereich [Zimmer](/de/dashboard/rooms).

<Steps>
  <Step title="Immobilie auswählen">
    Wählen Sie über die Immobilienauswahl die Unterkunft aus, für die Sie ein neues Zimmer oder eine neue Einheit erstellen möchten.
  </Step>

  <Step title="Zimmer öffnen">
    Navigieren Sie im Dashboard zum Bereich **Zimmer**.
  </Step>

  <Step title="Neue Einheit hinzufügen">
    Verwenden Sie die dort verfügbare Funktion zum Hinzufügen eines neuen Zimmers bzw. einer neuen Einheit.
  </Step>

  <Step title="Einheitsinformationen eingeben">
    Hinterlegen Sie die erforderlichen Informationen für das Zimmer oder die Einheit.

    Dazu können beispielsweise gehören:

    - **Zimmername oder Zimmernummer**, z. B. `Zimmer 101` oder `Apartment A2`
    - Weitere für die Einheit verfügbare Informationen
  </Step>

  <Step title="Einheit speichern">
    Speichern Sie die neue Einheit. Anschließend erscheint sie in der Zimmerübersicht der ausgewählten Immobilie.
  </Step>
</Steps>

## Stockwerk zuweisen

Zimmer können über den **Stockwerksplan** einer bestimmten Etage zugeordnet werden.

Öffnen Sie dazu:

**Einstellungen → Immobilie → Stockwerksplan**

Weitere Informationen finden Sie unter [Einstellungen](/de/dashboard/settings).

Beispiele für Stockwerke sind:

- Erdgeschoss
- 1. Obergeschoss
- 2. Obergeschoss
- Untergeschoss
- Penthouse

<Info>
  Erstellen Sie das Zimmer zunächst im Bereich [Zimmer](/de/dashboard/rooms). Anschließend können Sie es im Stockwerksplan der entsprechenden Etage zuweisen.
</Info>

## Geräte einer Einheit zuordnen

Smarte Geräte können einem Zimmer oder einer Einheit zugeordnet werden.

Dazu können beispielsweise gehören:

- **Smart Locks** für den Zimmerzugang
- **Thermostate** für Heizung und Klimatisierung
- **Sensoren** für Fenster, Türen, Bewegung oder andere Raumzustände
- **Schalter und Beleuchtung**
- Weitere kompatible IoT-Geräte

Die Geräte selbst werden im Bereich [Geräte](/de/dashboard/devices) verwaltet.

Weitere Informationen zu den verschiedenen Gerätetypen finden Sie unter:

- [Smart Locks](/de/devices/smart-locks)
- [Thermostate](/de/devices/thermostats)
- [Sensoren](/de/devices/sensors)
- [Gateways](/de/devices/gateways)
- [Lichter & Schalter](/de/devices/lights-and-switches)

<Info>
  Geräte müssen nicht zwingend beim ersten Anlegen eines Zimmers zugeordnet werden. Sie können die Gerätezuweisung später über die entsprechenden Geräte- und Zimmerfunktionen ergänzen.
</Info>

## Immobilieninformationen bearbeiten

Die Stammdaten der aktuell ausgewählten Immobilie werden unter [Einstellungen](/de/dashboard/settings) verwaltet.

Dort können Sie unter anderem folgende Informationen bearbeiten:

- Immobilienbild
- Name
- Code
- Firmenname
- Beschreibung
- Check-in-Zeit
- Check-out-Zeit
- PMS-Typ
- Zeitzone
- Adresse
- Standortkoordinaten
- Kontaktinformationen
- WLAN-Informationen
- IoT-Konfiguration

Speichern Sie Änderungen über **Änderungen speichern**.

## Zimmer oder Einheit bearbeiten

Um Informationen einer vorhandenen Einheit zu ändern:

<Steps>
  <Step title="Zimmer öffnen">
    Navigieren Sie zu [Zimmer](/de/dashboard/rooms).
  </Step>

  <Step title="Einheit auswählen">
    Suchen Sie das gewünschte Zimmer oder die gewünschte Einheit.
  </Step>

  <Step title="Bearbeiten">
    Öffnen Sie die verfügbaren Bearbeitungsoptionen für die Einheit.
  </Step>

  <Step title="Änderungen speichern">
    Prüfen Sie die aktualisierten Informationen und speichern Sie die Änderungen.
  </Step>
</Steps>

<Warning>
  Seien Sie besonders vorsichtig, wenn Sie Zimmernamen oder Zimmernummern ändern, während aktive oder zukünftige Buchungen vorhanden sind. Bei einer PMS-Integration können Zimmerinformationen mit den entsprechenden Daten des PMS verknüpft sein.
</Warning>

## Verbindung zu Buchungen

Zimmer und Einheiten bilden die Grundlage für die Zuordnung von Reservierungen.

Im Bereich [Buchung](/de/dashboard/booking) können Buchungen den entsprechenden Zimmern bzw. Einheiten zugeordnet werden.

Je nach PMS-Konfiguration können Buchungs- und Zimmerinformationen automatisch mit SUITEe synchronisiert werden.

<Info>
  Prüfen Sie bei einer PMS-Integration, dass die Zimmerstruktur in SUITEe korrekt zur Zimmerstruktur Ihres PMS passt.
</Info>
