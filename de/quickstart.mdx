Dieser Leitfaden führt Sie auf dem schnellsten Weg durch die ersten Schritte mit SUITEe. Am Ende haben Sie sich angemeldet, sich auf dem Dashboard orientiert und die wichtigsten Bereiche der Plattform verstanden.

## Voraussetzungen

Stellen Sie vor dem Start sicher, dass Sie Folgendes zur Hand haben:

- **Anmeldedaten** (E-Mail und Passwort), die Ihnen vom SUITEe-Team oder Ihrem Unterkunfts-Administrator bereitgestellt wurden
- Einen **modernen Webbrowser** — Chrome, Firefox, Safari oder Edge (neueste Version empfohlen)
- Eine **stabile Internetverbindung**

<Info>
  Falls Sie Ihre Anmeldedaten noch nicht erhalten haben, wenden Sie sich an Ihren Unterkunft-Manager oder das SUITEe-Support-Team unter [suite-e.com/contact-us](https://suite-e.com/contact-us/).
</Info>

## Erste Schritte

<Steps>
  <Step title="Öffnen Sie die SUITEe-Plattform">
    Öffnen Sie Ihren Webbrowser und rufen Sie **[hotel.suite-e.com](https://hotel.suite-e.com/)** auf. Sie sehen den Anmeldebildschirm mit dem SUITEe-Logo sowie Feldern für E-Mail und Passwort.

    <Frame>
      <img src="/images/login-german.png" alt="SUITEe Anmeldeseite mit E-Mail- und Passwortfeldern" />
    </Frame>
  </Step>

  <Step title="Geben Sie Ihre Anmeldedaten ein und melden Sie sich an">
    1. Geben Sie Ihre **E-Mail-Adresse** in das E-Mail-Feld ein
    2. Geben Sie Ihr **Passwort** in das Passwortfeld ein
    3. Klicken Sie auf die Schaltfläche **"Anmelden"**

    <Tip>
      SUITEe unterstützt sowohl **Englisch (EN)** als auch **Deutsch (DE)**. Sie können die Sprache über den Sprachauswähler auf der Anmeldeseite wechseln — achten Sie auf das Flaggensymbol oder das Sprachkürzel.
    </Tip>
  </Step>

  <Step title="Schließen Sie die OTP-Verifizierung ab (falls aufgefordert)">
    Für zusätzliche Sicherheit fordert SUITEe Sie möglicherweise auf, ein **Einmalpasswort (OTP)** einzugeben:

    1. Prüfen Sie Ihre E-Mails oder Ihr Telefon auf einen 4- bis 6-stelligen Code
    2. Geben Sie den Code in das Verifizierungsfeld ein
    3. Klicken Sie auf **"Verifizieren"**

    <Warning>
      OTP-Codes laufen nach wenigen Minuten ab. Wenn der Code abgelaufen ist, klicken Sie auf **"Code erneut senden"**, um einen neuen zu erhalten.
    </Warning>
  </Step>

  <Step title="Erkunden Sie das Admin-Dashboard">
    Nach der Anmeldung landen Sie auf dem **Admin-Dashboard** — Ihrer zentralen Steuerzentrale. Folgendes finden Sie hier:

    | Dashboard-Bereich | Was angezeigt wird |
    | :--- | :--- |
    | **Heutige Check-ins/Check-outs** | Gäste, die heute ankommen und abreisen |
    | **Zimmerstatus** | Welche Zimmer belegt, frei oder in Reinigung sind |
    | **Gerätestatus** | Status aller Smart Devices (Schlösser, Thermostate, Sensoren) |
    | **Aktuelle Warnmeldungen** | Probleme, die Aufmerksamkeit erfordern (niedriger Akkustand, Offline-Geräte) |
    | **Energieübersicht** | Zusammenfassung des Energieverbrauchs über alle Zimmer hinweg |

    <Frame>
      <img src="/images/dashboard-overview.png" alt="SUITEe Admin-Dashboard mit wichtigen Kennzahlen und Zimmerstatus" />
    </Frame>
  </Step>

  <Step title="Nehmen Sie Ihre Einstellungen vor">
    Passen Sie Ihr Nutzererlebnis an:

    - **Dunkelmodus / Heller Modus** — Wechseln Sie nach Ihren Wünschen zwischen visuellen Themes
    - **Sprache** — Wechseln Sie jederzeit zwischen Englisch und Deutsch
    - Das System merkt sich Ihre Auswahl über verschiedene Sitzungen hinweg
  </Step>
</Steps>
