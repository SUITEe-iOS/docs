Einer der größten Vorteile von SUITEe ist, dass es sich um eine **Retrofit-Lösung** handelt. Das bedeutet, dass Sie Ihre Unterkunft mit smarter Technologie modernisieren können — **ohne Bauarbeiten, Neuverkabelung oder kostspielige Renovierungen**.

## Wichtige Fakten zur Installation

| Aspekt | Details |
| :--- | :--- |
| **Bauarbeiten erforderlich?** | Nein — die Geräte werden in die bestehende Ausstattung integriert |
| **Neuverkabelung erforderlich?** | Nein — smarte Schlösser ersetzen vorhandene Schlösser, ohne die Verkabelung zu verändern |
| **Renovierungen erforderlich?** | Nein — die Installation erfolgt schnell und mit minimaler Beeinträchtigung des Betriebs |
| **Durchschnittliche Zeit pro Zimmer** | Etwa **1 Stunde** |
| **Wer kann installieren?** | Ihr bestehendes Haustechnik-Team, Elektriker oder Techniker |
| **Vorkonfiguration** | Die Geräte werden **vorkonfiguriert** geliefert — sie müssen nur montiert werden |

<Info>
  SUITEe-Geräte werden vorkonfiguriert und einsatzbereit geliefert. Sie müssen die Geräte lediglich **physisch in den Räumen montieren**. Nach der Montage erscheinen sie automatisch im Dashboard und können den entsprechenden Zimmern zugeordnet werden.
</Info>

## Reihenfolge der Installation

Die Reihenfolge, in der Sie die Geräte einrichten, **ist wichtig**. Gehen Sie wie folgt vor:

<Steps>
  <Step title="Gateways zuerst einrichten">
    Das **Gateway** ist die zentrale Kommunikationseinheit. Es muss online und verbunden sein, bevor andere Geräte mit dem Dashboard kommunizieren können.

    1. Schließen Sie das Gateway an eine **Steckdose** an
    2. Verbinden Sie es mit Ihrem **WLAN-** oder **Ethernet-Netzwerk**
    3. Warten Sie etwa **30 Minuten**, damit eine stabile Verbindung mit der SUITEe Cloud hergestellt werden kann
    4. Prüfen Sie im Dashboard, ob das Gateway als **„Online“** angezeigt wird

    <Warning>
      **Überspringen Sie diesen Schritt nicht.** Wenn das Gateway nicht online ist, können andere Geräte keine Daten an das Dashboard senden oder Anweisungen empfangen. Beginnen Sie daher immer mit dem Gateway.
    </Warning>
  </Step>

  <Step title="Smarte Türschlösser installieren">
    Ersetzen oder erweitern Sie bestehende Türschlösser durch smarte SUITEe Schlösser:

    - Entfernen Sie die vorhandene Schlosshardware
    - Installieren Sie das smarte Schloss mit dem mitgelieferten Montageset
    - Setzen Sie die Batterien ein
    - Das Schloss verbindet sich automatisch mit dem Gateway und erscheint im Dashboard

    Installieren Sie Schlösser an:

    - Zimmertüren
    - Gebäudeeingangstüren
    - Türen zu Gemeinschaftsbereichen wie Spa oder Fitnessraum
    - Brandschutztüren mit dafür geeigneten smarten Brandschutzschlössern
  </Step>

  <Step title="Smarte Thermostate installieren">
    Ersetzen Sie die vorhandene Thermostatsteuerung:

    - Entfernen Sie das alte Thermostat
    - Installieren Sie das smarte SUITEe Thermostat an derselben Position
    - Verbinden Sie es mit der vorhandenen Verkabelung entsprechend der Standard-Thermostatverkabelung
    - Das Thermostat verbindet sich mit dem Gateway und erscheint im Dashboard
  </Step>

  <Step title="Sensoren installieren">
    Platzieren Sie die Sensoren in den einzelnen Zimmern:

    | Sensor | Installationsort |
    | :--- | :--- |
    | **Präsenzsensor** | An der Decke oder hoch an der Wand mit freier Sicht auf den Raum |
    | **Fenstersensor** | Am Fensterrahmen als magnetischer Kontakt |
    | **Temperatursensor** | An der Wand auf einer repräsentativen Höhe |
    | **Wassersensor** | Auf Bodenhöhe in der Nähe von Badezimmern oder unter Waschbecken |

    Sensoren werden üblicherweise mit **Klebematerial oder Schrauben** befestigt — Bohrarbeiten an den Wänden sind nicht erforderlich.
  </Step>

  <Step title="Licht-/Schaltmodule installieren (optional)">
    Wenn Sie eine smarte Lichtsteuerung verwenden möchten:

    - Ein qualifizierter Elektriker ersetzt herkömmliche Schalter durch smarte Schaltmodule
    - Die Module passen in Standard-Unterputzdosen
    - Nach der Installation verbinden sie sich über das Gateway mit dem System

    <Info>
      Lichtmodule sind optional. Sie können zunächst nur mit Schlössern, Thermostaten und Sensoren starten und die Lichtsteuerung später ergänzen.
    </Info>
  </Step>
</Steps>

## Neue Immobilie im Dashboard einrichten

Nachdem die physische Installation abgeschlossen ist, richten Sie die Immobilie im SUITEe Dashboard ein:

<Steps>
  <Step title="Im Admin-Dashboard anmelden">
    Öffnen Sie [hotel.suite-e.com](https://hotel.suite-e.com/) und melden Sie sich mit Ihren Zugangsdaten an.
  </Step>

  <Step title="Immobilie hinzufügen">
    Navigieren Sie zu **Immobilien** und klicken Sie auf **„Neue Immobilie hinzufügen“**. Geben Sie folgende Informationen ein:

    - Name der Immobilie
    - Adresse
    - Anzahl der Einheiten/Zimmer
    - Kontaktinformationen
  </Step>

  <Step title="Einheiten (Zimmer) hinzufügen">
    Fügen Sie innerhalb der Immobilie jedes Zimmer oder Apartment hinzu:

    - Name/Nummer der Einheit
    - Einheitstyp
    - Etage (optional)
  </Step>

  <Step title="Geräte den Zimmern zuordnen">
    Sobald die Geräte im Dashboard online erscheinen, ordnen Sie jedes Gerät dem richtigen Zimmer zu:

    - Smartes Schloss mit der Zimmertür verknüpfen
    - Thermostat dem Zimmer zuordnen
    - Sensoren dem Zimmer zuordnen
  </Step>

  <Step title="PMS verbinden">
    Richten Sie die PMS-Integration ein, damit SUITEe Buchungsdaten empfangen kann:

    - Öffnen Sie **Einstellungen → Integrationen**
    - Wählen Sie Ihr PMS aus, z. B. Mews, Apaleo oder Clock+
    - Folgen Sie dem Einrichtungsassistenten für die Integration
    - Prüfen Sie, ob Testbuchungen korrekt synchronisiert werden
  </Step>
</Steps>

## Checkliste nach der Installation

Überprüfen Sie nach Abschluss der Installation, ob alles ordnungsgemäß funktioniert:

- [ ] Alle Gateways werden im Dashboard als **Online** angezeigt
- [ ] Alle smarten Schlösser sind **online** und reagieren auf Test-PINs
- [ ] Alle Thermostate sind **online** und zeigen die korrekten Temperaturen an
- [ ] Alle Sensoren sind **online** und erkennen Zustände korrekt — testen Sie dies beispielsweise durch Betreten und Verlassen der Räume
- [ ] Die PMS-Integration ist **aktiv** und Buchungen werden synchronisiert
- [ ] Eine Testreservierung erstellt automatisch die entsprechenden Zugangsdaten
- [ ] Die manuelle Schlüsselöffnung funktioniert bei allen Schlössern als Backup

<Tip>
  **Profi-Tipp:** Erstellen Sie nach der Installation eine **Testreservierung** in Ihrem PMS und durchlaufen Sie selbst die vollständige Gästereise — vom Erhalt der Check-in-E-Mail bis zur Verwendung des PIN-Codes zum Öffnen der Tür. So können Sie sicherstellen, dass der gesamte Ablauf funktioniert, bevor die ersten echten Gäste anreisen.
</Tip>
