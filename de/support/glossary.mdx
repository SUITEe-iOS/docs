Ein vollständiges Glossar der Begriffe, die in der SUITEe Plattform und in dieser Dokumentation verwendet werden. Alle Definitionen sind bewusst einfach und verständlich formuliert.

## A

| Begriff | Definition |
| :--- | :--- |
| **Access Management (Zugangsverwaltung)** | Steuert, wer welche Türen zu welchem Zeitpunkt öffnen darf. SUITEe verwaltet Zugänge automatisch anhand von Reservierungen und ermöglicht zusätzlich die manuelle Vergabe von Zugangsberechtigungen. |
| **Audit Trail (Audit-Protokoll)** | Eine Aufzeichnung darüber, wer was zu welchem Zeitpunkt getan hat — zum Beispiel, wer eine bestimmte Tür zu welcher Uhrzeit geöffnet hat. Wird für Sicherheit und Nachvollziehbarkeit verwendet. |
| **Automatisierung** | Aktionen, die automatisch ausgeführt werden, ohne dass jemand sie manuell durchführen muss. SUITEe automatisiert den Zugang, z. B. das Erstellen und Ablaufen von Schlüsseln, sowie das Energiemanagement, z. B. die Anpassung der Temperatur. |

## C–D

| Begriff | Definition |
| :--- | :--- |
| **Check-in** | Der Zeitpunkt, zu dem ein Gast ankommt und Zugang zu seinem Zimmer erhält. Mit SUITEe erfolgt dies digital — eine Rezeption ist dafür nicht erforderlich. |
| **Check-out** | Der Zeitpunkt, zu dem ein Gast abreist und seine Zugangsberechtigung abläuft. SUITEe führt dies automatisch zur geplanten Zeit durch. |
| **Dashboard** | Die zentrale Bedienoberfläche von SUITEe, über die Mitarbeiter alle Bereiche der Unterkunft verwalten — Reservierungen, Geräte, Zugänge, Energie und Benutzer. |

## E–G

| Begriff | Definition |
| :--- | :--- |
| **Eco-Modus** | Energiesparmodus für Zimmer. Er wird verwendet, wenn ein Zimmer leer ist oder sich zwischen zwei Gästeaufenthalten befindet. Die Heiz- bzw. Kühlleistung wird auf ein Minimum reduziert, um Energie zu sparen. |
| **Gateway** | Ein kleines Hub-Gerät, das alle smarten Geräte wie Schlösser, Thermostate und Sensoren mit dem Internet und dem SUITEe Cloud-Dashboard verbindet. Jede Unterkunft benötigt mindestens ein Gateway. |
| **DSGVO** | Datenschutz-Grundverordnung — eine europäische Verordnung, die sicherstellt, dass personenbezogene Daten sicher und rechtmäßig verarbeitet werden. SUITEe ist vollständig DSGVO-konform. |
| **Gästemodus** | Komfortmodus für Zimmer. Dabei werden die normalen Temperatureinstellungen verwendet, wenn ein Gast eingecheckt hat und sich im Zimmer aufhält. |
| **Gäste-Web-App** | Eine Website und keine herunterzuladende App, die Gäste auf ihrem Smartphone zur Verwaltung ihres Aufenthalts verwenden. Darüber können sie Türen öffnen, die Temperatur steuern, die Registrierung abschließen und weitere Funktionen nutzen. Ein Download aus einem App Store ist nicht erforderlich. |

## I–M

| Begriff | Definition |
| :--- | :--- |
| **Integration** | Die Verbindung zwischen zwei Softwaresystemen, beispielsweise zwischen dem PMS und SUITEe. Durch die Integration können Daten automatisch zwischen den Systemen übertragen werden. |
| **Mobiler Schlüssel** | Ein digitaler Schlüssel auf dem Smartphone des Gastes, mit dem Türen geöffnet werden können. Er funktioniert über die Gäste-Web-App im Browser des Smartphones. |

## O–P

| Begriff | Definition |
| :--- | :--- |
| **OTP** | One-Time Password (Einmalpasswort) — ein temporärer Sicherheitscode, normalerweise mit 4–6 Ziffern, der zur Identitätsprüfung während der Anmeldung per E-Mail oder Telefon gesendet wird. |
| **PMS** | Property Management System — die zentrale Software für Hotelbuchungen und Hotelmanagement. Beispiele sind Mews, Apaleo und Clock+. SUITEe verbindet sich mit Ihrem PMS, um Buchungsdaten abzurufen. |
| **PIN-Code** | Ein numerischer Code, den Gäste über das Tastenfeld des smarten Schlosses eingeben, um die Tür zu öffnen. Jeder Gast erhält einen eindeutigen PIN, der ausschließlich während seines Aufenthalts gültig ist. |
| **Immobilie (Property)** | Ein Gebäude oder Standort, der über SUITEe verwaltet wird — beispielsweise ein Hotel, ein Apartmentkomplex oder eine Ferienunterkunft. |

## R–S

| Begriff | Definition |
| :--- | :--- |
| **Retrofit** | Die Installation neuer smarter Geräte in einem bestehenden Gebäude ohne umfangreiche Renovierungsarbeiten. Die Geräte von SUITEe sind so konzipiert, dass sie bestehende Hardware schnell ersetzen oder darin integriert werden können. |
| **Self-Check-in** | Ein Check-in, bei dem der Gast keine Unterstützung durch einen Mitarbeiter an der Rezeption benötigt. Über die Gäste-Web-App und seine Zugangsdaten kann der Gast die Unterkunft und sein Zimmer selbstständig betreten. |
| **Sensor** | Ein kleines Gerät in einem Zimmer, das bestimmte Zustände erkennt, beispielsweise Präsenz, Temperatur, geöffnete Fenster oder Wasseraustritt. Die Sensordaten bilden die Grundlage für die Automatisierungen von SUITEe. |
| **Smartes Schloss** | Ein digitales Türschloss, das mit einem Smartphone über einen mobilen Schlüssel oder mit einem PIN-Code geöffnet werden kann. Es ersetzt oder erweitert herkömmliche schlüsselbasierte Schlösser und wird mit Batterien betrieben. |
| **Sync / Synchronisierung** | Der Prozess, bei dem zwei Systeme Daten austauschen und gegenseitig aktuell halten. SUITEe synchronisiert sich mit Ihrem PMS, damit Reservierungs- und Zimmerstatusdaten konsistent bleiben. |

## T–U

| Begriff | Definition |
| :--- | :--- |
| **Thermostat** | Ein Gerät zur Steuerung der Temperatur, also Heizung und Kühlung, in einem Raum. Die smarten Thermostate von SUITEe passen sich automatisch an Präsenz und Reservierungsstatus an. |
| **Einheit (Unit)** | Ein einzelnes Zimmer, Apartment oder ein anderer Bereich innerhalb einer Immobilie. Beispielsweise ist „Zimmer 101“ oder „Apartment A2“ eine Einheit innerhalb der Immobilie „Hotel Sunrise“. |

## D (Gerätestatus)

| Begriff | Definition |
| :--- | :--- |
| **Device Health (Gerätestatus)** | Der aktuelle Zustand eines smarten Geräts — einschließlich Batteriestand, Online-/Offline-Status und der Information, ob das Gerät ordnungsgemäß funktioniert. Der Gerätestatus wird über das Dashboard überwacht. |
