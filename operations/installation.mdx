One of SUITEe's biggest advantages is that it is a **retrofit solution**. This means you can modernise your property with smart technology **without construction, rewiring, or expensive renovations**.

## Key installation facts

| Aspect | Details |
| :--- | :--- |
| **Construction needed?** | No — devices fit into existing hardware |
| **Rewiring needed?** | No — smart locks replace old locks without changing wiring |
| **Renovations needed?** | No — installation is quick and non-disruptive |
| **Average time per room** | About **1 hour** |
| **Who can install?** | Your existing maintenance team, electricians, or technicians |
| **Pre-configuration** | Devices arrive **pre-configured** — just mount them |

<Info>
  SUITEe devices are shipped pre-configured and ready to use. All you need to do is **physically mount them** in the rooms. Once mounted, they automatically appear in the dashboard and can be assigned to rooms.
</Info>

## Installation order

The order in which you set up devices **matters**. Follow this sequence:

<Steps>
  <Step title="Set up gateways first">
    The **gateway** is the communication hub. It must be online and connected before any other devices can communicate with the dashboard.

    1. Plug the gateway into a **power outlet**
    2. Connect it to your **Wi-Fi** or **ethernet network**
    3. Wait **~30 minutes** for it to establish a stable connection with the SUITEe cloud
    4. Verify in the dashboard that the gateway shows as **"Online"**

    <Warning>
      **Do not skip this step.** If the gateway is not online, other devices cannot send data to the dashboard or receive instructions. Always start with the gateway.
    </Warning>
  </Step>

  <Step title="Install smart door locks">
    Replace or enhance existing door locks with SUITEe smart locks:
    - Remove the existing lock hardware
    - Install the smart lock using the provided mounting kit
    - Insert batteries
    - The lock will automatically connect to the gateway and appear in the dashboard

    Install locks on:
    - Room doors
    - Building entrance doors
    - Amenity area doors (spa, gym, etc.)
    - Fire-rated doors (using fire-rated smart locks)
  </Step>

  <Step title="Install smart thermostats">
    Replace existing thermostat controls:
    - Remove the old thermostat
    - Install the SUITEe smart thermostat in the same location
    - Connect to existing wiring (follows standard thermostat wiring)
    - The thermostat connects to the gateway and appears in the dashboard
  </Step>

  <Step title="Install sensors">
    Place sensors in each room:

    | Sensor | Where to Install |
    | :--- | :--- |
    | **Occupancy sensor** | Ceiling or high wall with clear view of the room |
    | **Window sensor** | On the window frame (magnetic contact) |
    | **Temperature sensor** | Wall-mounted at representative height |
    | **Water sensor** | Floor level near bathrooms or under sinks |

    Sensors are typically attached with **adhesive or screws** — no drilling into walls required.
  </Step>

  <Step title="Install light/switch modules (optional)">
    If you want smart lighting control:
    - A qualified electrician swaps traditional switches for smart switch modules
    - They fit into standard electrical boxes
    - Once installed, they connect through the gateway

    <Info>
      Light modules are optional. You can start with just locks, thermostats, and sensors, and add lighting control later.
    </Info>
  </Step>
</Steps>

## Setting up a new property in the dashboard

Once physical installation is complete, set up the property in the SUITEe dashboard:

<Steps>
  <Step title="Log in to the Admin Dashboard">
    Go to [hotel.suite-e.com](https://hotel.suite-e.com/) and log in with your credentials.
  </Step>

  <Step title="Add your property">
    Navigate to **Properties** and click **"Add New Property"**. Enter:
    - Property name
    - Address
    - Number of units/rooms
    - Contact information
  </Step>

  <Step title="Add units (rooms)">
    Within the property, add each room or apartment:
    - Unit name/number
    - Unit type
    - Floor (optional)
  </Step>

  <Step title="Assign devices to rooms">
    As devices come online in the dashboard, assign each one to the correct room:
    - Link the smart lock to the room door
    - Link the thermostat to the room
    - Link sensors to the room
  </Step>

  <Step title="Connect your PMS">
    Set up the PMS integration to start receiving booking data:
    - Go to **Settings → Integrations**
    - Select your PMS (Mews, Apaleo, or Clock+)
    - Follow the integration setup wizard
    - Verify that test bookings sync correctly
  </Step>
</Steps>

## Post-installation checklist

After completing installation, verify everything is working:

- [ ] All gateways are **online** in the dashboard
- [ ] All smart locks are **online** and responding to test PINs
- [ ] All thermostats are **online** and showing correct temperatures
- [ ] All sensors are **online** and detecting correctly (test by walking in/out of rooms)
- [ ] PMS integration is **active** and bookings are syncing
- [ ] A test reservation creates access credentials automatically
- [ ] Manual key override works on all locks (as a backup)

<Tip>
  **Pro tip:** After installation, create a **test reservation** in your PMS and walk through the complete guest journey yourself — from receiving the check-in email to using the PIN code to open the door. This ensures everything works end-to-end before real guests arrive.
</Tip>
