A complete glossary of terms used throughout the SUITEe platform and this documentation. All definitions are written in plain, simple language.

## A

| Term | Definition |
| :--- | :--- |
| **Access Management** | Controlling who can enter which doors and when. SUITEe manages access automatically from reservations and also allows manual access grants. |
| **Audit Trail** | A record of who did what and when — for example, who opened a specific door at what time. Used for security and accountability. |
| **Automation** | Actions that happen automatically without anyone doing them manually. SUITEe automates access (creating/expiring keys) and energy (adjusting temperature). |

## C–D

| Term | Definition |
| :--- | :--- |
| **Check-In** | When a guest arrives and accesses their room. In SUITEe, this happens digitally — no reception desk needed. |
| **Check-Out** | When a guest departs and their access expires. SUITEe handles this automatically at the scheduled time. |
| **Dashboard** | The main control screen in SUITEe where staff manage everything about the property — reservations, devices, access, energy, and users. |

## E–G

| Term | Definition |
| :--- | :--- |
| **Eco Mode** | Energy-saving mode for rooms. Used when a room is empty or between guest stays. Reduces heating/cooling to the minimum to save energy. |
| **Gateway** | A small hub device that connects all smart devices (locks, thermostats, sensors) to the internet and the SUITEe cloud dashboard. Each property needs at least one. |
| **GDPR** | General Data Protection Regulation — a European law that ensures personal data is handled safely and legally. SUITEe is fully GDPR-compliant. |
| **Guest Mode** | Comfortable mode for rooms. Normal temperature settings used when a guest is checked in and occupying the room. |
| **Guest Web App** | A website (not a downloadable app) that guests use on their phone to manage their stay — unlock doors, control temperature, complete registration, and more. No app store download needed. |

## I–M

| Term | Definition |
| :--- | :--- |
| **Integration** | The connection between two software systems (e.g., PMS and SUITEe). The integration allows data to flow automatically between them. |
| **Mobile Key** | A digital key on the guest's smartphone that can unlock doors. Works through the Guest Web App in the phone's browser. |

## O–P

| Term | Definition |
| :--- | :--- |
| **OTP** | One-Time Password — a temporary security code (usually 4–6 digits) sent to your email or phone for identity verification during login. |
| **PMS** | Property Management System — the main hotel booking and management software. Examples include Mews, Apaleo, and Clock+. SUITEe connects to your PMS to read booking data. |
| **PIN Code** | A numeric code that guests enter on the smart lock's keypad to open the door. Each guest gets a unique PIN that is valid only for their stay. |
| **Property** | A building or location managed through SUITEe — for example, a hotel, apartment complex, or vacation rental property. |

## R–S

| Term | Definition |
| :--- | :--- |
| **Retrofit** | Installing new smart devices into an existing building without major renovation. SUITEe's devices are designed to replace or fit into existing hardware quickly. |
| **Self Check-In** | When a guest checks themselves in without needing a receptionist. They use the Guest Web App and their access credentials to enter the property and their room independently. |
| **Sensor** | A small device placed in rooms that detects conditions like occupancy (is someone there?), temperature, open windows, or water leaks. Sensors provide the data that drives SUITEe's automations. |
| **Smart Lock** | A digital door lock that can be opened with a smartphone (mobile key) or PIN code. Replaces or enhances traditional key-based locks. Runs on batteries. |
| **Sync / Synchronise** | When two systems share data and stay updated with each other. SUITEe syncs with your PMS to keep reservation and room status data consistent. |

## T–U

| Term | Definition |
| :--- | :--- |
| **Thermostat** | A device that controls the temperature (heating and cooling) in a room. SUITEe's smart thermostats adjust automatically based on occupancy and reservation status. |
| **Unit** | A single room, apartment, or space within a property. For example, "Room 101" or "Apartment A2" is a unit within the property "Hotel Sunrise". |

## D (Device Health)

| Term | Definition |
| :--- | :--- |
| **Device Health** | The current condition of a smart device — including battery level, online/offline status, and whether it's working properly. Monitored from the dashboard. |
